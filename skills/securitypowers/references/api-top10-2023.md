# OWASP API Security Top 10 — 2023

Summary for review work. Authoritative text: https://owasp.org/API-Security/editions/2023/en/0x11-t10/ (OWASP API Security Project, CC BY-SA 4.0). Use it for any HTTP API: FastAPI, Flask, Express, a REST backend behind a SPA, an internal service.

| ID | Risk | What to look for in code | Map to |
|---|---|---|---|
| API1:2023 | Broken Object Level Authorization (BOLA) | Handler loads an object by an id from the request and never checks that the caller owns it or may read it | A01:2025, ASVS V8.2.2 |
| API2:2023 | Broken Authentication | Token not verified server-side, weak or missing rate limit on login and reset, long-lived tokens, credentials in URLs | A07:2025, ASVS V6, V9 |
| API3:2023 | Broken Object Property Level Authorization | Response model returns internal fields; request model accepts fields the caller must not set (mass assignment: `role`, `owner_id`, `is_admin`) | A01:2025, ASVS V8.2.3 |
| API4:2023 | Unrestricted Resource Consumption | No pagination cap, no upload size limit, no timeout, no rate limit, a costly operation (job submit, report, LLM call) callable in a loop | A06:2025, ASVS V2.4 |
| API5:2023 | Broken Function Level Authorization | Admin route reachable by a normal user; authorization done by hiding the button in the UI | A01:2025, ASVS V8.2.1 |
| API6:2023 | Unrestricted Access to Sensitive Business Flows | A flow that is harmless once but harmful when automated (sign-up, purchase, quota grant) with no anti-automation control | A06:2025, ASVS V2.4 |
| API7:2023 | Server Side Request Forgery | Server fetches a URL or host the caller controls (webhook URL, import from URL, S3 endpoint) without an allowlist; reaches metadata or internal services | A01:2025, ASVS V1.3.6 |
| API8:2023 | Security Misconfiguration | Debug mode, verbose errors with stack traces, permissive CORS (`*` with credentials), missing security headers, default credentials, TLS off between services | A02:2025, ASVS V13 |
| API9:2023 | Improper Inventory Management | Old API versions still deployed, undocumented endpoints, staging hosts reachable from the Internet with production data | A02:2025, ASVS V13.4 |
| API10:2023 | Unsafe Consumption of APIs | Data from a third-party API trusted without validation; redirects followed blindly; no timeout on outbound calls | A08:2025, ASVS V2.2 |

Notes:
- ASVS ids above point to the chapter or requirement closest to the risk. Check the exact id in `asvs-5.0.md` before you cite it in a report.
- For each finding, report the path (input → missing check → object or function reached), as `owasp-security` requires.
